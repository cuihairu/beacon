## A. 真机交互项（16 条）

### A-1｜跨 DPI 拖动不错乱（todo.md:45）

- 前置：C-DPI（两块缩放不同的屏，如 100% + 200%）。已有证据：场景 R/R3（38750239155）覆盖重启位置与普通拖动。
- 步骤：① 面板贴屏 A，逐个拖 tile 到屏 B 松手；② 面板整体跨屏拖动；③ 拖动过程中往复跨屏来回；④ 拖完重启应用。
- 通过标准：tile 落点与松手位置一致（无跳变/爬行），文字不裁不糊，重启后位置在原屏原位；拖动中无闪烁（WM_DPICHANGED 与拖动互抢已在代码面修）。
- 参考：71 条清单 2.13 / 2.15。

### A-2｜URL 端到端打开（todo.md:58）

- 前置：任一连接配置了控制台/详情 URL（如 http 连接、GitHub 仓库链接）。
- 步骤：① tile 右键/详情窗点「打开控制台」类链接；② 观察默认浏览器。
- 通过标准：默认浏览器打开且地址与配置一致（拼接无重复斜杠/无未替换模板占位符）；无 URL 时不渲染可点项。
- 已有证据：TemplateRendererTests 覆盖拼接纯函数半。

### A-3｜Toast 发送/点击/激活路由（todo.md:63）

- 前置：Windows 通知中心可用；通知规则已启用（71 条清单 2.9）。已有证据：AUMID 自愈场景 F5t（38494525200）。
- 步骤：① 制造告警（断网 C-DISCONNECT 或 mock 服务器置 error）等 Toast 弹出；② 点击 Toast 正文；③ 点掉后从通知中心历史再点一次。
- 通过标准：Toast 弹出（含图标与标题）；点击后应用置前并直达对应 tile 的详情窗（路由正确，非只激活主窗）；通知中心历史条目点击同样路由。

### A-4｜托盘图标颜色/刷新周期（todo.md:66）

- 前置：E1 日志。已有证据：tile 更新场景 G7a（38%→95%，75s 内）。
- 步骤：① 健康态观察托盘图标颜色；② mock 置 error/恢复健康，掐表观察托盘图标变色时延；③ 对照设置的刷新周期。
- 通过标准：托盘图标颜色与档位一致（绿/黄/红/离线灰），变色时延 ≤ 刷新周期 + 一次轮询，无长期滞留旧色。

### A-5｜悬浮 tile 点击穿透观感（todo.md:71）

- 前置：已钉至少一个 tile 且开启悬浮（0341abc 已加 WS_EX_TRANSPARENT，不用全局钩子）。
- 步骤：① 在悬浮 tile 的空白边缘/间隙处点击/框选，观察下层窗口；② 点 tile 内容区（数据/灯位）。
- 通过标准：空白处点击落到下层窗口（穿透成立，不挡操作）；内容区点击仍由 tile 响应（打开详情）；悬浮窗不抢焦点、不出现在 Alt-Tab。

### A-6｜多显示器越界回收（todo.md:77）

- 前置：C-DPI 双屏，tile 拖到副屏。
- 步骤：① 设置里禁用副屏（或拔线）→ 观察 tile；② 重新启用；③ 改低主屏分辨率再恢复。
- 通过标准：副屏消失后 tile 全部回到可见主屏内（无「藏在屏外」的不可达 tile，重启后同样）；分辨率变化同理；pins.json 不被写坏。

### A-7｜RFC §6.2.7 四项铁律（todo.md:80）

- 步骤（逐项）：① 点 tile → 打开该组件详情（钻取成立）；② 制造告警 → L0 面板本体**不**弹 Toast/不出声，只有状态灯变色（Toast 归通知引擎，即 A-3 那条链）；③ 检查 L0/tile 面与悬浮 tile 的可点项——只有零风险「打开链接」类，无 Deploy/Restart 等需确认动作（它们只在 L2/L3）；④ 拖动/刷新/告警全程不抢焦点，Alt-Tab 列表与任务栏无 Beacon 条目（托盘图标除外）。
- 通过标准：四项全过；任何一项违例记现象+截图。

### A-8｜托盘图标同步改色（todo.md:81）

- 已有证据：tile/胶囊改色 G4/G5（38953986133）。
- 步骤：① 设置里给某 tile 配 colorOverride → 看托盘图标；② 重置颜色 → 再看；③ 改全局档位色 → 再看。
- 通过标准：托盘图标跟随同一配色源变化（优先级 Widget > 档位 > 默认），与 tile/胶囊同刻变色，重置回默认。

- 通过标准：各档行为与 RFC §6.2.8 表一致；观感无抖动/撕裂/掉帧；full 档动画不 CPU/GPU 爆表（任务管理器粗看）；真人裁量观感「可接受」即过，不满意记具体现象。
