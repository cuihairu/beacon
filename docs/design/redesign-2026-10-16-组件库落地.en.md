
# Component library as-built (Phase 2 as-built)

> 2026-10-16. Where the redesign-plan §5 component library actually landed in the repo. The design draft is external input; this document records **the in-repo facts that have already landed**:
> the single token source, the component factory inventory, the consolidated surface, and the not-yet-consolidated remainder. For the vocabulary and the contract see `redesign-2026-10-16-契约.md` (widget side).

## 1 Token system (single source and delegation)

| Dimension | Single source | Placement |
|---|---|---|
| Font size / corner radius / spacing | `src/Beacon.App/Services/DesignTokens.cs` | 8 font sizes + 6 corner radii + spacing scale; the only source on the App-side C# surface |
| Corner radius (XAML surface) | `src/Beacon.App/App.xaml` resource mirror | WinUI 3 has no `x:Static`, so XAML can only use `StaticResource`; **the C# and XAML copies must be changed in sync** (both sides carry sync-warning comments) |
| Color / severity colors | `UiPalette` (App) + `PaletteResolver`/`HighContrastPalette` (Core) | Component factories never hold color; brushes are resolved by the caller and passed in |
| Base foreground/background | `ThemeColors` (App.Windows) | Progress-bar track base color and the like are derived via `Opacity` |
| Motion | `MotionEngine` (App) | Single source for durations/easing; components do not embed animation constants |
| Size / DPI | `DpiLayoutMath` (Core) | DIP→px conversion happens exactly once at the Win32 boundary (same convention in all four windows) |
| Progress tiers | `ProgressTiers` (Core, 0.8/0.98 thresholds) | PinnedHost `BarFillColor` delegates to it; the App no longer holds the thresholds |

Value-equivalence discipline: consolidation is always **zero value change** (anchored by the CI S/O/Q/F5/G pixel assertions); off-scale literals like
`3` (detail-table row spacing, chip top/bottom spacing) are brought into components at their original values with comments — visuals are never changed as a side effect of consolidation.

## 2 Component factory inventory (`src/Beacon.App/Components/`)

Conventions: `internal static class` factories; components hold typography/geometry (via DesignTokens) and **never hold color** (brushes come from the caller);
conditional children are always added imperatively via `Add` (a null inside a collection initializer blows up at runtime).

| Factory | Pieces | Adopted by (in-repo facts) |
|---|---|---|
| ComponentText | Caption / Body | QuickPanel status rows/event rows (a517594) |
| ComponentIcon | StatusDot | QuickPanel row-leading light |
| ComponentSurface | Card | Vocabulary piece (settings card face follows the same convention) |
| ComponentBadge | Count | Vocabulary piece |
| ComponentDivider | Horizontal | Vocabulary piece |
| ComponentStatus | Indicator / OfflineHollow | DetailWindow header light (bf95dde); the hollow variant = the capsule offline-banner convention |
| ComponentMetric | Value | Vocabulary piece (waiting on Phase 3 binding) |
| ComponentProgress | FillColor / Bar | FillColor delegates to ProgressTiers; Bar is a static-bar vocabulary piece |
| ComponentKeyValue | Row | DetailWindow detail table (1db70de) |
| ComponentList | Vertical | DetailWindow detail table container |
| ComponentCard | Status | Vocabulary piece (a Surface.Card composition) |
| ComponentAction | Button / Item / Menu / Link | Detail action area + QuickPanel pin context menu (bb86927); Link is a vocabulary piece |
| ComponentLayout | Row / Column / Columns / SectionLabel / When | QuickPanel's three rows and empty-section collapse, Detail header row/action row/section labels, PinnedHost six columns (8caf0b5) |
| ComponentFeedback | Empty / Loading / Error / Offline | Vocabulary piece (5489352); the current UX convention = empty-section hiding + XAML banners |

## 3 Not-yet-consolidated remainder (advanced surface by surface; does not block the phase)

- Bespoke Thickness: chip `Padding(8,3,8,3)`, capsule/panel XAML padding — handled along the way when the corresponding surfaces get componentized.
- The SettingsWindow button family (about 17 `new Button` sites): form buttons, not 「动作」 (action) vocabulary; waiting for the form-componentization batch.
- XAML-surface layout (QuickPanelWindow.xaml's Grid/Stack): XAML has no factory to land in; the resource-mirror constraint stays.

## 4 Proof surface

The proof for adopted pieces = CI pixel assertions (green as long as value equivalence holds). The proof surface for the vocabulary pieces (Surface/Badge/Divider/Metric/StatusCard/
Link/Column/Feedback four states) = the **independent visual example page** at the end of Phase 2 (todo phasing row 9) and the Phase 3 binding engine;
landing with no adopting surface is the by-design vocabulary stage, not a finished state.
