
# 组件库落地（Phase 2 as-built）

> 2026-10-16。redesign-plan §5 的组件库在仓内的实际落点。设计稿是外部输入，本文记录**已落地的仓内事实**：
> 令牌单源、组件工厂清单、收编面与未收编余量。词汇表与契约见 `redesign-2026-10-16-契约.md`（widget 侧）。

## 1 令牌体系（单源与委托）

| 维度 | 单源 | 落点 |
|---|---|---|
| 字号/圆角/间距 | `src/Beacon.App/Services/DesignTokens.cs` | 8 档字号 + 6 档圆角 + 间距刻度；App 侧 C# 面唯一来源 |
| 圆角（XAML 面） | `src/Beacon.App/App.xaml` 资源镜像 | WinUI 3 无 `x:Static`，XAML 只能走 `StaticResource`；**C# 与 XAML 两处必须同步改**（两侧均有同步警示注释） |
| 色彩/状态色 | `UiPalette`（App）+ `PaletteResolver`/`HighContrastPalette`（Core） | 组件工厂一律不持色，brush 由调用面解析后传入 |
| 基础前景/背景 | `ThemeColors`（App.Windows） | 进度条轨道底色等经 `Opacity` 派生 |
| 动效 | `MotionEngine`（App） | 时长/缓动单源，组件不内嵌动画常量 |
| 尺寸/DPI | `DpiLayoutMath`（Core） | DIP→px 只在 Win32 边界换算一次（四窗同口径） |
| 进度档位 | `ProgressTiers`（Core，0.8/0.98 阈值） | PinnedHost `BarFillColor` 委托，App 不再持有阈值 |

值等价纪律：收编一律**值零变化**（CI S/O/Q/F5/G 像素断言锚定）；`3`（详情表行距、chip 顶底距）等
off-scale 字面量按原值收进组件并注释，不在收编顺带改视觉。

## 2 组件工厂清单（`src/Beacon.App/Components/`）

约定：`internal static class` 工厂；组件持排版/几何（走 DesignTokens），**不持配色**（brush 由调用面给）；
条件子元素一律命令式 `Add`（集合初始化器内 null 运行时炸）。

| 工厂 | 件 | 采用面（仓内事实） |
|---|---|---|
| ComponentText | Caption / Body | QuickPanel 状态行/事件行（a517594） |
| ComponentIcon | StatusDot | QuickPanel 行首灯 |
| ComponentSurface | Card | 词汇件（设置卡面同口径） |
| ComponentBadge | Count | 词汇件 |
| ComponentDivider | Horizontal | 词汇件 |
| ComponentStatus | Indicator / OfflineHollow | DetailWindow 头灯（bf95dde）；空心变体=胶囊离线横幅口径 |
| ComponentMetric | Value | 词汇件（候 Phase 3 绑定） |
| ComponentProgress | FillColor / Bar | FillColor 委托 ProgressTiers；Bar 静态条词汇件 |
| ComponentKeyValue | Row | DetailWindow 详情表（1db70de） |
| ComponentList | Vertical | DetailWindow 详情表容器 |
| ComponentCard | Status | 词汇件（Surface.Card 组合） |
| ComponentAction | Button / Item / Menu / Link | Detail 动作区 + QuickPanel pin 右键（bb86927）；Link 词汇件 |
| ComponentLayout | Row / Column / Columns / SectionLabel / When | QuickPanel 三行与空区收起、Detail 头行/动作行/区段签、PinnedHost 六列（8caf0b5） |
| ComponentFeedback | Empty / Loading / Error / Offline | 词汇件（5489352）；现 UX 口径=空区隐藏+XAML 横幅 |

## 3 未收编余量（逐面推进，不阻塞期次）

- bespoke Thickness：chip `Padding(8,3,8,3)`、胶囊/面板 XAML 内边距——等对应面组件化时顺带。
- SettingsWindow 按钮族（约 17 处 `new Button`）：表单按钮，非「动作」词汇，候表单组件化批。
- XAML 面布局（QuickPanelWindow.xaml 的 Grid/Stack）：XAML 无工厂可落，维持资源镜像约束。
